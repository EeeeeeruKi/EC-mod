# Layered Armor（重ね着防具）

Minecraft 1.20.1 / Forge 用のMODです。**Curios API** に「重ね着（頭・胴・脚・足）」の4つのスロットを追加し、バニラの防具欄と同じように防具を装備できるようにします。

必須MODは **Curios API** だけです。下の対応MODは、入っていれば自動で連携します。

## できること

- 重ね着スロットに防具を着けると、バニラの防具欄の防具と**両方の効果**が乗ります
  - 防御力・防具強度・ノックバック耐性（ネザライトなど）
  - 防護・炎上耐性・爆発耐性・飛び道具耐性・トゲ・水中呼吸・水中歩行・氷渡り・ソウルスピード・スニーク速度上昇・修繕などのエンチャント
  - 束縛の呪いも有効です（重ね着スロットから外せなくなります）
  - カメの甲羅の水中呼吸、金の防具でピグリンが怒らない、革のブーツで粉雪の上を歩ける、カボチャでエンダーマンが怒らない
  - 胴の重ね着スロットのエリトラで滑空できます
- **耐久値の減りはバニラの防具欄が優先**です。バニラ欄に防具がある部位は、重ね着の防具は削れません。バニラ欄が空の部位だけ、重ね着の防具が削れます
- **見た目もバニラの防具欄が優先**です。バニラ欄が空の部位だけ、重ね着の防具が表示されます（Curiosの表示切り替えボタンで隠すこともできます）

## 対応MOD（必須ではありません）

| MOD | 対応内容 |
|---|---|
| Cold Sweat | 重ね着の防具の防寒・耐熱、縫い付けた防寒材、温度系の効果も入ります |
| Apotheosis | 重ね着の防具の接辞（属性・特殊効果）、ソケットの宝石、Apotheosisのエンチャントが効きます |
| Mekanism | ジェットパック・メカスーツ（モジュール・落下ダメージ吸収・ステップ補助・重力制御・HUD・見た目など）が重ね着でも動きます |
| Create Stuff 'N Additions | ジェットパック・外骨格が重ね着でも動きます（見た目も表示されます） |
| Advanced AE | 量子アーマーの機能が重ね着でも動きます |
| Cosmetic Armor Reworked | Cosmetic Armorで見た目が表示されていればそれを表示します。Cosmetic Armorで透明にしている部位は、重ね着の防具を表示します（重ね着スロットはCosmetic Armorの設定の影響を受けません） |
| Corpse | 死体の見た目にも同じルールで重ね着の防具を反映します |

## 補足

- 重ね着スロットには、バニラの防具欄に入れられるアイテム（防具・エリトラ・カボチャ・頭など）を、同じ部位のスロットにだけ入れられます
- もともとCurios用に作られているアイテムは、重ね着スロットには入りません
- 他MODの「胴に着けているアイテムだけを見る」タイプの特殊効果は、上の表のMOD以外は重ね着では動かないことがあります
