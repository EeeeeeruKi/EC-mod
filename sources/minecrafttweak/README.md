# minEcraft twEEk

Quark を前提MODにして、Quark にない小さな改善をたくさん詰め込んでいくためのMODです。
Quark にある機能は入れません。機能は最初はすべてオフです。

- `neoforge/` … Minecraft 1.21.1 / NeoForge
- `forge/` … Minecraft 1.20.1 / Forge

## 機能の一覧

| 番号 | 機能 | 最初 | 詳細設定 |
|---|---|---|---|
| 1 | 経験値オーブの素早い吸収 | オフ | 1a 待ち時間（0〜2ティック） |
| 2 | システムの言語（言語の画面の一覧のいちばん上に「システムの言語」を足す。選ぶとパソコンの言語に合わせる） | **オン** | なし |
| 3 | カスタムメニューBGM（URL かファイルの .ogg / .mp3 / .wav をメニューで流す。「参照」でファイルを選べる） | オフ | 3a 曲のURL・ファイル、3b 音量（%）、3c くり返す |
| 4 | ポーズ画面のBGM（タイトル画面と同じ曲。Aether などの曲も） | オフ | なし |
| 5 | 英語でも検索（クリエイティブ・レシピ本・JEI・EMI・AE2 の端末で、英語の名前でも探せる） | オフ | なし |

- 文字の詳細設定（3a など）は、設定コードでは「,」や空白などを `%2C` のような形にして入れます（空は `~`）。

## 設定画面の開き方

- MOD一覧の「設定」ボタン
- タイトル画面の、言語ボタンの左にある小さいボタン（コンパレーターの絵。あいていなければアクセシビリティの右。v1.9.0 から）
- Quark の設定画面（Q メニュー）の、分類の並びのいちばん下にある「minEcraft twEEk」ボタン（v1.7.2 から）

設定画面は Quark の Q メニューと同じ並べ方です（v1.9.0 から）。
ホームに、アイコン付きのボタンが1行に3つずつ並びます（「設定コード」＋分類）。分類を押すとその分類の機能の一覧が開き、オン/オフと「詳細」を変えられます。

## 機能の足し方

1. `feature/<分類>/` に `Feature` を継承したクラスを作る（`ArmorStandArmsFeature` が見本）。
2. `core/Features.java` の static ブロックの一番下に `add(new ○○Feature());` を1行足す。
   Quark にすでにある機能は作らない。
3. 機能ごとの詳細設定は `addOptions()` の中で `intOption` / `doubleOption` / `boolOption` を使って作る。
   作った順に `1a`, `1b`… の番号が付き、設定画面の「詳細」ボタンから変更できる。
4. `lang/ja_jp.json` と `en_us.json` に `minecrafttweak.feature.<id>` と `.desc`、詳細設定の `minecrafttweak.feature.<id>.<設定id>`（と `.desc`）を足す。

イベントの処理の最初で `isEnabled()` を確認すれば、設定画面でオフにした瞬間から止まります。

## 設定コード（インポート/エクスポート）

「項目番号-値」を「,」でつないだ文字列で、まとめて設定できます。

- `N` … N番の機能のオン/オフ（`t` / `f`）
- `N`＋英字 … N番の機能の詳細設定（`a` が1つ目、`b` が2つ目…。値は数値、または `t` / `f`）

例: `1-t,1a-2`

- 設定画面のホームの「設定コード」を開いて、欄に貼って「インポート」。
- コードは2つに分かれています。
  - 「MODのコード」… このMODの機能と Quark（q）
  - 「描画のコード」… バニラ（v）・Sodium（s）・Sodium Extra（se）
- コピーされるのは、初期値と違う設定だけです。
- 「圧縮」をオンにすると、`MT1.` で始まる短い英数字のコードになります（短いコードは圧縮すると逆に長くなるので、そのときはそのまま）。インポートの欄にはそのまま貼れます。
- 「初期化」をオンにしてインポートすると、コードに入っている側（MOD / 描画）の設定を先にすべて初期値に戻してから読み込みます。
- 2つのコードは、空白で区切って一緒に貼れます。
- コマンド: `/minecrafttweak import 1-t,1a-2`、`/minecrafttweak list`（OP権限が必要）。

番号は Features.java に足した順なので、新しい機能は必ず一番下に足してください。
バニラや他MODの項目は `client/code/VanillaCodes.java` と `client/code/ModCodes.java` にあり、こちらも新しい項目は一番下に足します。

## Quark の項目番号（q）

Quark（Zeta）の設定のうち、オン/オフと数値の設定を `q` ＋6けたの番号で変えられます（例: `q123456-f`）。
番号は設定の場所（`tweaks.automatic_recipe_unlock.enabled` など）から計算しているので、Quark のバージョンが変わっても、同じ設定の番号はほぼ変わりません。
番号の一覧は、ゲーム内の「ID一覧」の Quark のタブで見られます。Quark の設定はサーバーの設定なので、`/minecrafttweak import` でも変えられます。

## 設定コードの項目番号（バニラ・Sodium・Sodium Extra）

頭文字＋番号で、バニラや他MODの設定も設定コードで変えられます（例: `v1-12,v10-f,s2-1,se34-t`）。

- 値は `t` / `f`、数値、選択肢の番号（バニラは設定の番号、Sodium などは並び順で 0 から）か名前で書けます。
- クライアントの設定なので、設定画面の欄からインポートします（サーバーのコマンドでは変えられません）。
- 入っていないMODや、そのバージョンに無い設定は飛ばされます。「コピー」では、今使える項目だけがコードになります。
- ゲーム内では設定画面の「ID一覧」で、番号と今の値を見られます。

## 使っているライブラリ

- [JavaMP3](https://github.com/delthas/JavaMP3)（MIT ライセンス）… MP3 を読むために `thirdparty/javamp3` に入れています。ライセンスは jar の `META-INF/licenses/JavaMP3-LICENSE.txt` にあります。

## ビルドに使う外部のファイル

「英語でも検索」は JEI と EMI の API を使います。`neoforge/libs/` と `forge/libs/` に、それぞれのローダー版の JEI と EMI の jar（`jei-<loader>.jar`、`emi-<loader>.jar`）を置いてからビルドしてください（このリポジトリには入れていません）。
