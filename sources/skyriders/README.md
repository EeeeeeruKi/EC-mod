# Sky Riders

エアライド系のマシンに乗って走るmodです（試作版・1.21.1 Fabric）。

- マシンは自動で前に進みます。A/Dで曲がり、左右を素早く切り返すとクイックスピンです
- スペース/シフトを押している間はブレーキしながらチャージし、離すとブーストします。前にいる敵を吸い込み、ほおばっている時に押すと星をはき出します。空中で押すと急降下します
- 滑空中はWで機首を下げ（速くなる）、Sで機首を上げます（速さを使って上昇）
- Qでスペシャル、Eで降車（近くに空いているマシンがあれば乗り換え）

ビルド: `fabric/` で `gradle build`（Java 21、Gradle 8.14）。
