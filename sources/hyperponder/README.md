# Hyperlink Ponder

Hyperlink / Hyperlink-E のハイパーアイテムとフメツウィザー（召喚・倒し方・怒った時の挙動・不死性）を、Ponder の思案画面で説明する MOD のソースです。

- `neoforge-1.21.1/` … Hyperlink-E（NeoForge 1.21.1）向け
- `forge-1.20.1/` … Hyperlink 本家（Forge 1.20.1）向け

アイテムを持って W キー長押しで思案画面が開きます。MOD ID は `hyperponder`、Ponder と Hyperlink（`hyperdaimc`）が必要です。
